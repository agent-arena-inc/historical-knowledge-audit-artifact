# Release inventory

This inventory describes the Stage 1 prototype and its development plan.
Recomputation of cached automated results is available now. Independent human
validation is planned and is not represented as completed evidence.

Status labels:

- **Available**: supplied in this release.
- **Generated**: deterministically created by an existing artifact script.
- **Pending verification**: supplied automated evidence awaiting human validation.
- **Planned**: development-stage work, not a completed result or an additional
  pre-submission experiment.

## Stage 1 submission handoff

1. Use the generated cached-judgment table for preliminary numerical claims;
   retain its denominators and automated-evidence status.
2. Select the submission commit after its verification workflow succeeds.
3. Upload that commit's verified reviewer archive through the submission portal
   or review server so reviewers do not depend on access to a private repository.
4. Check the proposal and appendix for consistency with this inventory, and
   check the submitted documents and their metadata for author identifiers.

The planned validation and access work above belongs in the proposal's
development plan. It does not require new experiments to package the current
Stage 1 prototype. The remaining handoff is recorded in
[SUBMISSION_CHECKLIST.md](SUBMISSION_CHECKLIST.md).
